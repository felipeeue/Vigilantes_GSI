# Vigilantes_GSI

Projeto completo Backend + Frontend para gerenciamento de vigilantes da DPEMT.

## Backend
cd backend  
npm install  
node server.js  

## Frontend
cd frontend  
npm install  
npm start  

## Observações
- Adicione `serviceAccountKey.json` do Firebase na pasta backend  
- Backend roda na porta 3000, frontend na 3001 (React)
